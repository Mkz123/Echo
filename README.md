# 回声 · ECHO

一个单文件的时间回溯解谜小游戏。

每一关你只有有限的时间。时间耗尽或按下 Enter，*此刻的你*会留在原地，替你守住刚刚踩过的按钮；然后时间倒流，新的"你"从起点出发，踩着过去的自己留下的道路继续前进。一个人打不开的门，要靠一重又一重的自己接力打开。

## 运行

无需构建、无依赖，直接用浏览器打开 `echo.html` 即可。

## 操作

- 方向键 / WASD 移动
- Enter 留下当前的自己并回溯时间

## 章节

游戏共四个章节、十五个关卡：梦的入口、留下来的人、接力、外婆的木箱、借来的箱子、一人分饰两角、闹钟、交卷铃、检票口、两张车票、别害了过去的自己、三重奏、有人在等、所有的你、差一步。
