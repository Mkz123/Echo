# 第 47 号磁带 · TAPE 47

一个单文件的时间回溯解谜小游戏。

回声中继站已经空了 4017 天。维修单元 47 醒来时，核心舱传来一段断断续续的信号：「……开……门……」。可站里每一扇门都要两个人才能打开，而站里只剩下它。

它找到了一台示教磁带机。把自己录下来，倒带，再和录像里的自己一起开门。

## 运行

不用构建，也没有依赖。用浏览器直接打开 `echo.html` 就能玩。

## 操作

- 方向键 / WASD：移动
- 空格：原地等一步
- Enter：把这一卷录下来，然后倒带
- Z：倒带一格；R：重来本关
- 0–9、[ ]：选关；M：静音

## 玩法

- 每卷磁带只能录十几步（看上方的磁带长度）。
- 倒带之后，之前录下的每一卷都会和你同时重放。
- 压力板、培养箱、三秒电闸、单人闸机、反向门，都要靠几卷磁带配合。
- 如果一步会让磁带里的自己被门夹住（卡带），游戏会拦下这一步，并告诉你原因。

## 章节

序章、五个章节和尾声，共十五关。每通过一关，会恢复一段船员当年的录音。

| 章节 | 舱段 | 关卡 |
| --- | --- | --- |
| 序章 | 维修舱 | 唤醒 |
| 第一章 | 温室 | 双人门禁 · 接力 · 培养箱 · 借来的培养箱 |
| 第二章 | 实验室 | 一机两用 · 过载电闸 · 三秒 |
| 第三章 | 登舰廊桥 | 单人闸机 · 撤离名单 |
| 第四章 | 受损舱段 | 卡带 · 三卷磁带 |
| 终章 | 核心舱 | 门那边的人 · 所有的磁带 |
| 尾声 | 维修舱 | 第 47 号磁带 |

> 有些门，一个人打不开。所以总有人，替你按住它。

## 六格入场动画

打开游戏后，点击「接收信号」或按 Enter 观看 32 秒的末日赛博朋克多宫格序幕。支持暂停、重播、跳过、M 静音，以及系统「减少动态效果」设置。播完直接进入序章。

原画已内嵌，仍然是无需联网、无需依赖的单文件游戏。分镜、素材与验证说明见 [docs/OPENING.md](docs/OPENING.md)，视频预览见 [output/opening-preview.mp4](output/opening-preview.mp4)。
