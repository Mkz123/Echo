# 六格序幕 · 入场动画

为《第 47 号磁带》制作的 32 秒多宫格动态分镜。末日赛博朋克空间站，采用冷青、锈色金属、琥珀色灯光。六幅原画通过裁切、缓慢推镜、依次揭幕、亮度聚焦和字幕淡入形成动画；不包含人物逐帧表演或配音。

## 观看与操作

直接打开 `echo.html`，点击「接收信号」或按 Enter 播放。无需构建、联网或额外依赖；WebP 原画已内嵌在 HTML 中。

- 空格：暂停 / 继续；切换到其他标签页自动暂停。
- Enter / Escape：「跳过序幕」，立即进入序章。
- M：静音。点击「重播」可重新播放开场。
- 支持系统「减少动态效果」设置：停止推镜、粒子及分格揭幕，保留叙事与字幕。
- 首次用户点击或按键后才启动声音。

播放结束自动进入原有第 0 关，六格叙事替代原先同样内容的开场文字日志。关卡、故事后续与解谜规则保留。

## 素材与维护

- `assets/opening-storyboard.png`：1536 × 1024 六格原画，使用内置 imagegen 生成。
- `assets/opening-storyboard.webp`：压缩版本，内嵌到单文件游戏中。
- `docs/opening-art-prompt.txt`：完整生成提示词。
- `output/opening-preview.mp4`：1280 × 720、24 fps、32 秒、带合成环境音的预览。
- `output/opening-desktop.png` / `output/opening-mobile.png`：桌面和手机标题页截图。
- `output/shot-1.png` 至 `output/shot-7.png`：各段静帧。

HTML 中 `CIN_SHOTS` 维护时间与字幕；`cinPanelRects()` 维护桌面拼贴及手机六格布局；`cinCue()` 调用现有游戏音效合成器。没有外部素材请求或追踪服务。
