# 四页记忆 · 15 秒翻页漫画片头

《第 47 号磁带》的片头以四页多宫格漫画展开。厚墨线、排线、印刷网点与旧纸色替代旧版写实原画；纸页带卷边、背面受光及投影，依次从右向左掀开。内置 imagegen 生成八格原画，代码负责排版、镜头微动、纸页卷起和音效。

## 叙事与玩法一致

过去的 47 分别存在于温室、维修间、实验室和登舰廊桥。最后一页把这些记忆保留在各自独立的画格中，以全息着色、扫描纹与跨格连线呈现同步关系；当下的 47 独自在废弃空间站，出口也只在这里出现。没有把多个虚影并排放进同一个房间。

这些场景是片头的总览；单关实际使用的场景数量仍由协作人数决定，与 README 和 `SCENES` 规则一致。

三次纸页翻动分别从第 4、8、12 秒开始，每次约 0.65 秒，计入 15 秒总时长。没有新增人物或提前揭露结局。

## 观看与控制

用浏览器直接打开 `echo.html`，点击「接收信号」或按 Enter。无需开端口、构建或联网；八格 WebP 原画、排版代码及合成音效都内嵌在 HTML 中。

- 空格：暂停 / 继续；离开标签页自动暂停。
- Enter / Escape 或「跳过序幕」：进入序章。
- M：静音；「重播」：从第 1 页重新开始。
- 系统「减少动态效果」：取消卷页与镜头微动，直接切换漫画页，叙事与总时长保留。

手机竖屏使用上下分格，桌面与横屏使用左右分格。游戏关卡、章节和解谜逻辑保留，正式游戏仍使用键盘。

## 素材与维护

- `assets/opening-storyboard.png`：八格原画，四列两行，内置 imagegen 生成。
- `assets/opening-storyboard.webp`：内嵌游戏的压缩原画。
- `docs/opening-art-prompt.txt`：完整生成提示词。
- `output/opening-preview.mp4`：1280 × 720、24 fps、15 秒、带合成音效。
- `output/shot-1.png` 至 `output/shot-8.png`：八个叙事节点。
- `output/page-turn-1.png` 至 `output/page-turn-3.png`：卷页过程。
- `output/opening-desktop.png`、`output/opening-mobile.png`、`output/opening-mobile-shot.png`、`output/opening-landscape.png`：布局检查。

`CIN_DURATION` 是总时长；`CIN_SHOTS` 控制字幕与音效时间；`CIN_PAGES` 控制四页场景；`cinPageLayout()` 控制画格；`cinDrawTurn()` 绘制纸背、卷边和投影。影片采用多宫格动态漫画形式，角色本体为静态原画。

## 验证

在断网 Chrome 下直接以 file 协议加载，外部网络请求为零，浏览器脚本错误为零。覆盖 1440 × 900 桌面、390 × 844 手机竖屏和 844 × 390 横屏；全部八个叙事节点、四页与三次卷页；鼠标和键盘启动、暂停、重播、静音、跳过、减少动态效果设置；实际计时约 15 秒自动进入序章，并验证移动操作。与改动前对比，关卡定义、谜题模拟及章节编号保持一致。
