## 对齐情况

生成绘画可以很好地保持总体构图，但当前润色稿仍有少量道路边缘偏移，不能将其直接标记为像素级校验通过。预览允许叠加原始连续路径轮廓、隐藏网格与机关坐标；路径锁定对照稿使用原始地图的精确区域，并将种植区边缘裁切在非通行区域内。

后续正式背景应以锁定轮廓为依据，在不改变道路位置的情况下完成整景边缘润色。门、按钮、箱子、闸机和机器人继续作为独立图层。这次先交付温室整景方向样图，没有批量声称 75 张整景原画已完成，也没有改动正式关卡。
