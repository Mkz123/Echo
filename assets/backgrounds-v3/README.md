# 记忆场景 · 完整整景背景 03

按正式游戏实际出现的场景制作：15 关、36 个关卡与场景组合、35 张独立背景。第 15 关空间站与第 1 关使用相同原始地图，因此共用背景。没有补齐无用的 75 个组合。

## 直接看效果

用浏览器打开 [preview.html](preview.html)，无需端口服务、联网或依赖。预览内嵌全部 WebP 图片；上方关卡选择器只列出该关实际存在的场景，下方提供 36 个组合的缩略图。

默认显示完整整景，不画网格。可按需叠加原始可走区域、隐藏网格、机关位置。支持方向键切换关卡、保存 WebP、打开独立 PNG。

## 素材与来源

- `paintings/`：35 张完整 PNG 原画。
- `webp/`：对应的 35 张 WebP，用于轻量预览。
- `guides/`：14 个唯一布局的原始连续路径双色图。
- `layouts.json`：源游戏地图、可走区域、机关、初始门状态与未来轨迹；每关所有场景共用同一套坐标。
- `manifest.json`：36 个实际组合到原画、预览图及路径参考的映射。
- `jobs.json`、`prompts/`：35 个实际背景任务及最终提示词。第 05 关温室复用已确认的 v2 原画，来源提示词位于 `../map-study-v2/prompts/`。
- `references/`：维修间、实验室、廊桥的三张主题母稿及提示词，仅用于统一画风，不是额外关卡背景。
- `review/`：每个场景的关卡总览及离线浏览器验证记录。
- `tools/build-preview.py`：从现有原画重新生成 WebP、画册与总览，不调用生成服务。
- `tools/check-preview.cjs`：检查离线画册、36 个组合切换、检查层及窄屏显示。

使用内置 imagegen 按图单独生成，并行处理独立任务；第 2、3 关的大片可走房间与第 14 关维修间、实验室的第三条通道做过针对性重绘。原画保存到项目后不依赖 .codex 的生成缓存。

## 对齐状态与使用范围

这批为**未接入游戏的整景原画提案**。每关构图以原始地图为参考，路径叠层与机关坐标直接取自游戏数据；这保证检查坐标一致，但不代表生成绘画的道路边缘已经逐像素锁定。部分边缘、宽度、端点及非通行区域仍需逐处修整，不能直接作为碰撞已校验的正式底图。

`echo.html`、玩法、关卡碰撞、机关位置、角色和音频没有修改。正式接入之前，应逐张依据叠层修齐地面轮廓，再叠加独立道具与角色。

预览导出工具需要 Python 与 Pillow；浏览器验证工具需要 Playwright 与本机 Chrome。日常查看画册无需这些依赖。
